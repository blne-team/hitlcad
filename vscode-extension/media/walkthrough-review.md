# Edit, save, review

1. In the Claude Code or Codex panel, ask for the change: *"Make the lid 2 mm thicker and use M3 × 16 screws."*
2. The agent edits the design's files. Every save rebuilds it, and only the parts whose inputs changed are rebuilt.
3. In the hitlcad panel you can orbit the assembly, read the results (fits, fasteners, collisions, manufacturability), see the structure and the bill of materials, switch configurations, tune parameters and pin notes. Then tell the agent *"address my pins"*.

To point at a feature, click a face, or a whole part with the viewer's filter on Solid. Your selection and open pins go to Claude Code or Codex with your next message, named by part and connector; **Copy for chat** copies them to paste anywhere.
