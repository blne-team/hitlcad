# Edit, save, review

1. In the Claude Code or Codex panel, ask for the change: *"Make the hook 30 mm deep and add a fillet where the arm meets the plate."*
2. The agent edits `model.py`. Every save rebuilds the design.
3. In the hitlcad panel you can orbit the model, read the checks, tune parameters and pin notes. Then tell the agent *"address my pins"*.

To point at a feature, click a face. Your selection and open pins go to Claude Code or Codex with your next message; **Copy for chat** copies them to paste anywhere.
